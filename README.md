**Inker** is a Markdown notes app built with **Tauri 2 + Vue 3 + Rust**.

## Installation

### Download the installer

Download the appropriate installer from [Releases](https://github.com/lencelg/inker/releases/latest):

### Build from source

Required environment:

- Node.js 20+
- Rust stable
- Tauri 2 system dependencies (Debian / Ubuntu):

```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

Install the Tauri CLI and build:

```bash
cargo install tauri-cli --version "^2"
git clone https://github.com/lencelg/inker.git
cd inker
npm install
cargo tauri build
```

Build artifacts are written to `target/release/bundle/deb/`.

### Development

```bash
npm install
cargo tauri dev
```

Frontend tests and type checks:

```bash
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```
